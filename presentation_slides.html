⚡ Bolt Insights

Intelligent Real-Time Execution Diagnostic Framework

Bridging C++ Query Execution with AI Agents via MCP

The Problem

  • Query engines (Spark, Presto) offload execution to native C++ backends (Bolt) via JNI.
  • When a query stalls or OOMs in C++, the JVM (Spark/Presto) is completely blind to why.
  • Logs are massive, hard to read in real-time, and disconnected from the orchestrator.

The Solution: Bolt Insights

A real-time diagnostic layer deeply embedded within the C++ execution engine.

  • TaskInsightSession: Attaches directly to a query task's lifecycle.
  • TaskSampleCollector: Asynchronously polls raw C++ stats (memory, drivers, IO).
  • InsightEngine: Evaluates rules against history to emit InsightEvents.

The 5 Core Insights

Insight Type Trigger Condition Meaning
query_stalled 0 drivers running for multiple samples Query is deadlocked or starved.
spill_detected In-memory buffers full, writing to disk Memory-bound, performance will drop.
scan_io_bound Table Scan blocked waiting for storage Storage is slow or network saturated.
output_backpressure Output buffers consistently >90% full Client/network consuming too slowly.
scan_low_selectivity Filter drops almost all read data Missing partitions/indexes, bad plan.
